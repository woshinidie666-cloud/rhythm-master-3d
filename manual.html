　打开音乐验收回放　打开 3D 接线教程

1．现在先做这三件事

  1. 保留现在的单片机调试连接。目前只有核心板接入电脑，不需要为了看回放临时接蜂鸣器或扬声器。
  2. 打开音乐回放，选“全部正确”。点“播放并听声音”，观察四轨灯、按键确认状态、29 个音符的记录和分数。再试“漏掉第 1 音”和“长音提前松手”。应分别看到 29、28、28 分。
  3. 打开 3D，先学看一根线。在接线步骤中暂停，依次看“① 起点”和“② 终点”。读完元件名、引脚名、定位提示再动手。看不清时按 Ctrl 并滚动滚轮；“手形拖动”用来平移，“自由转动”用来换角度。

本阶段通过条件：你能说出一根线的两个端点，而不是只记住“绿色线接右边”。颜色只辅助识别，端点名称和实物标记才决定接法。

2．元件与接头，先认清再装

东西怎么认识在这个项目里做什么
STM32F103ZET6 核心板蓝色板，上面有芯片、USB 接口；两侧是双排接头运行程序，控制灯、读按键、产生声音控制信号
排针 / 排母 / 杜邦线你照片里黄色塑料上露出金属针的是排针；带孔插座是排母；杜邦线有孔的一端是母头，有针的一端是公头已焊好的排针配杜邦母头；不要把裸线塞进孔里当可靠连接
洞洞板绿色板，每孔背面有独立铜环；白色网格是定位印刷固定、焊接电阻、灯、按钮和接头。独立铜环之间默认不相通，白线不是导线
LED有正负；未剪脚时通常长脚为正。剪过脚用万用表二极管档确认12 颗作四轨灯，另 1 颗候选作开机状态灯。每颗各串一个限流电阻
1kΩ 电阻用电阻档读约 1000Ω；无正负极候选 LED 限流值；模型的“1、2号脚”只是端号
10kΩ 电阻电阻档读约 10000Ω；无正负极按键上拉，避免没按时输入悬空
四脚按钮同组两脚未按也相通；跨组按下才相通。必须测量，不能靠外形猜四个节奏键；模式和开始键另占两路候选输入
OLED照片上标 GND、VCC、SCL、SDA显示状态与图形音符；控制芯片、分辨率及兼容电压还需确认，不能只凭四针认定 SSD1306
蜂鸣器、扬声器圆形两脚件和照片里的长条扬声器不是同一种负载；“＋”只表示极性，不能据此认定有源/无源与额定电压按赛题需能改变音高的发声方案。先确认型号，再确定驱动；不得直接接 MCU 输出脚

主板上的名称怎么读

PE0 的意思是 E 端口第 0 路，板上常简写 E0；PF0 对应 F0。3V3 是 3.3V，5V 是 5V，GND 是公共地。它们不是“任意一根针都能代替”。双排接头需要核对具体内外排；拍照方向改变后左右也改变，不能按屏幕左右猜。

看到模型的 Cxx / Rxx，表示模型列 / 行。翻到焊接面左右会镜像：用四角安装孔和板边编号确认方向，再找同一个实际孔。

充电宝只有一条线，这样连接

使用你已有的成品线：充电宝 → 核心板侧边供电插座。没有额外分线接头，不拆开线缆。先只接核心板，用万用表直流电压档测5V与3V3排针；实际输出可能4.5V，模型上的5V是设计目标，不是实测结果。

灯、按键与OLED候选电源由核心板3V3/GND引出；声音候选从核心板5V/GND引出，先确认插座到5V排针的通路、允许电流及带载电压，再确认发声器与驱动规格。不要另接第二路电源到5V针，不把4.5V或5V接入3V3。

两版按同一功能清单设计，均可观看同一份比赛回放；洞洞板用显式焊线，面包板靠同编号同侧五孔连通。洞洞板教程 · 双面包板教程。默认隐藏杂线，选步骤只显示一根；用“放大起点／终点”核对具体元件脚，全部导线开关仅用于排错。

3．万用表：只先用这三种测量

  1. 通断档：断电测。表笔先互碰确认会响；测按钮分组、地线是否接通，以及相邻焊点是否意外连在一起。不能带电使用通断或电阻档。
  2. 电阻档：断电、尽量单独测元件。确认手中 1kΩ 和 10kΩ；电路里其他支路会影响读数。
  3. 直流电压档：上电测。黑表笔在 COM，红表笔在 V/Ω 孔；黑接 GND，红测目标电源。不要把红笔放在电流孔后跨接电源。表笔只碰目标点，避免同时碰到相邻排针。
充电宝照片中的“4.5V–5A”等属于接口输出规格，不能仅看容量决定接法。正式连接前测所选接口实际电压。不要将 5V 送进 3V3 或普通 GPIO；采用单一路径供电，避免 ST-LINK、USB、外部电源的供电脚未经确认就并联。

4．从试接到焊接：每关通过才下一关

A．先在面包板试一灯一键

  1. 断开供电。把开发板固定，辨认候选 E0、F0、3V3、GND，核对具体排针位置。
  2. 单灯电气路径：PE0 → 1kΩ → LED 正极；LED 负极 → GND。电阻可以在 LED 两侧任一侧串联，不能绕过。
  3. 单键电气路径：PF0 → 按钮的一组；按钮另一组 → GND；PF0 同节点经 10kΩ → 3V3。先测按钮分组。面包板左右电源轨是否断开也要测。
  4. 检查 PE0 和 PF0 没短接、LED 电阻没被短路、3V3 与 GND 没接错。通过后才启用对应的一灯一键驱动程序。

通过条件：每次按下、松开都能可靠识别；LED 受控亮灭。此步骤目前尚未在你的外接电路上执行，内部自测程序不会点亮它。

B．扩成四轨三灯、四键，再加控制键和状态灯

候选分配：第 1 轨 PE0/PE1/PE2，第 2 轨 PE3/PE4/PE5，第 3 轨 PE6/PE7/PE8，第 4 轨 PE9/PE10/PE11（均按上、中、下排序）；状态灯 PE12。四个节奏键 PF0–PF3，模式 PF4，开始 PF5。每灯各用自己的 1kΩ；每按钮输入各用自己的 10kΩ 上拉。具体排针和板载占用仍须核实。

通过条件：依次点 12 灯时只有目标灯亮；逐个按键时只有对应输入变动；四轨自上向下独立流水。不能直接一次焊完再猜哪里接错。

C．加 OLED，再加声音驱动

屏幕候选信号是 PB6→SCL、PB7→SDA，GND 共地；VCC 采用已确认兼容的电压，模型为 3.3V 候选。先验证供电、上拉和通信，再验证开始/结束文字，最后图形音符。声音候选 PB0 控制驱动开关；驱动管脚序和声音器件额定值确认后才组装。模型中的 MOS、二极管、电容和声音支路只是候选方案，不可拿任意同外形器件替换后上电。

通过条件：屏幕内容稳定；发声频率可随音符改变；按键 TEST 松开停声；声音不使单片机复位或屏幕闪烁。

D．面包板整机验证后，再焊洞洞板

  1. 保存面包板接线照片和已验证引脚表。断电。按 3D 元件面摆件；保留 USB、调试口和安装孔的空间。
  2. 先焊接头和低矮电阻，再焊按钮、LED 等。每焊少量元件就检查一次，铜环不会因为在同一白格内就相通。
  3. 逐根按第 8 节表与 3D 对照：起点、终点、网络、孔号都核对。绝缘导线跨越其他网络；裸锡桥只连接计划中同网的相邻焊点。
  4. 焊接面与元件面镜像，翻板后重新核对方向。焊完检查虚焊、连锡、剪下的金属脚和裸线相碰。
  5. 断电通断检查全部地线和信号。再分模块上电，重新执行 A、B、C，而不是以“有电源灯亮”为通过。

5．打开、编译和调试程序

已经替你打开 Keil。桌面“节奏大师程序”里的 固件工程/debug-monitor/rhythm-monitor.uvprojx 是本次工程；双击即可打开。它是 RAM 内部自测工程，不是完整比赛烧录版。

  1. 左侧工程树：main.c 是芯片自测入口，rhythm_song.c 是乐谱和游戏判定，启动文件负责进入程序。
  2. 点工具栏 Build（或按 F7）。底部应显示 0 Error(s), 0 Warning(s)。看到报错先停，不把旧生成文件当作新编译成功。
  3. 本轮已通过 ST-LINK 将程序放到 RAM 自动运行，实际读取到 29 分、0 失败、结束标志 1。读取结果及原 Flash 备份已保存；测试后已恢复原 Flash 启动。
  4. 当前 Keil 工程关闭了自动更新 Flash 和自动载入。不要把“进入调试”理解为已经烧好正式程序。以后整机驱动确认后，会另提供明确的比赛工程和正式下载步骤。

6．遇到问题按这个顺序排查

现象先做什么
灯不亮先确认运行的程序确实启用了这一路 GPIO；再断电查 LED 正负、电阻是否串联、接头、共地。不要为了变亮去短接限流电阻。
按一下多次加分 / 没按也触发查按钮分组、上拉电阻、公共地、接触；程序用消抖后的新边沿判定。提前一直按住不能算到点按下。
OLED 黑屏测电源，再核对 GND/VCC/SCL/SDA 顺序和控制芯片/地址。不要靠提高供电电压试错。
有声但都是一个音高确认是不是只能固定频率发声的有源蜂鸣器；检查 PWM/驱动以及实际频率。扬声器不能直接替代蜂鸣器接 GPIO。
一响就复位检查供电跌落、地线、驱动、电容和负载电流；先断开声音支路定位。
ST-LINK 连接失败确认核心板有正常供电；核对 SWDIO→DIO、SWCLK→CLK、GND→GND；拔插前先断电。不把 TX/RX 当作 SWD。
长音失败先看 C 回放理解：头部有效窗口按下，持续保持，尾部有效窗口松开；提前松开、过晚松开都失败，只有完整成功才 +1。

7．整机完成后：模拟实操与比赛演示顺序

这一节是最终验收清单，不是“已全部通过”的记录。正式比赛固件的菜单和控制键行为尚待定版，不能承诺当前 PF4/PF5 已能执行这些操作。每项由实测结果打勾。
  1. 赛前断电检查：元件固定、焊点可靠、极性正确、供电口明确、全部共地；带上独立电源、连接线、万用表、程序备份和报告。
  2. 独立供电：正式演示不使用电脑供电。上电观察可控指示灯闪烁 3 秒后保持常亮，计时确认。
  3. 四轨流水：展示至少四轨，每轨至少三颗实体 LED，自上向下可独立显示；不能用 OLED 代替基础项实体 LED。
  4. 短音：展示正确按、漏按、提前持续按、过晚按和错轨按。成功与失败应可区分；同一音符不能重复加分。
  5. 长音：展示正确按住并松开，以及提前松手、延迟松手。解释头部和尾部的判定时刻；连续灯带及两个通过时刻须按赛题要求核对。
  6. 双轨：至少两条轨道同时出现音符，各自独立判定，不能按一轨带动另一轨成功。
  7. 按键发声 TEST：四个按键分别展示按住发声、松开停止。本基础项不要求特定频率。
  8. 音乐游戏：OLED 显示开始提示和下落图形，新局分数为 0。按附件《年华似锦》D 大调、86 BPM 的 29 个音演奏，四轨都有音。全正确应得 29 分；音高误差满足原曲一个半音以内，旋律可辨认。
  9. 结束与重开：OLED 显示结束，最终分数保持；重新开局清零。长音仅完整完成后加 1，不拿“按下就加分”代替。
  10. 提交材料：按赛题准备自编程序、设计报告与要求的演示材料。比赛评分为报告 20＋基础 40＋发展 60，总 120；其中指定音乐项上限 20 分，不等于游戏 29 分。

赛前至少独立电源完整演示三遍，记录失败项并修复；重复次数是我们建议的自检方式，不是官方额外要求。扩展功能在基础和指定乐曲稳定后再加。
