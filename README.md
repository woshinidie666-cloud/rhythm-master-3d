# 节奏大师 · 三维接线与组装教学

[打开三维网页](https://woshinidie666-cloud.github.io/rhythm-master-3d/)

面向电路初学者的 STM32F103ZET6 电路设计草稿。包含真实三维孔、排针、引脚、元件与导线，支持 171 个组装步骤和 116 根接线的逐根查看。

## 怎么看

- **点击查看**：点元件、引脚或导线，查看中文作用与接法。元件说明中可以单独抽离，旋转观察，再返回原来的步骤。
- **手形拖动**：左键拖动平移。**自由转动**：左键拖动旋转。三种模式均可右键旋转、中键平移。
- **Ctrl + 滚轮**：放大或缩小模型；快捷角度可切换元件面、焊接面及四个侧面。
- **接线教学**默认一次只显示当前一根线。对照 **① 起点、② 终点**，分别点“放大看起点”“看整根走线”“放大看终点”。
- 默认最高画质，播放默认每步 6 秒；可以暂停、调节速度或手动前后切步。

初次下载模型较大，请等待加载。网页全部资源内嵌，没有第三方运行依赖，也不上传浏览者的数据。下载 `index.html` 后可双击离线查看；浏览器需支持 WebGL。

## 设计范围

洞洞板、STM32 核心板、13 颗 LED 与限流电阻、6 个按键与上拉电阻、OLED、候选声音驱动与电源连接。说明卡包含引脚解释、建议规格、候选型号、官方资料与待确认项目。

这是可交互的候选设计。开发板内外排映射、实际供电路径、OLED 兼容电压、发声器额定参数和部分尺寸尚需实物核对；动画验收不代表电气验收。请按说明卡逐项确认，再安排面包板试接与洞洞板焊接。

显示库为 Three.js 0.160.0，许可证见 [THREE-LICENSE.txt](THREE-LICENSE.txt)。网站版本为桌面离线教学版的副本；Blender 源文件另行保存在本机桌面项目文件夹。
