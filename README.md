[双面包板接线版](https://woshinidie666-cloud.github.io/rhythm-master-3d/breadboard.html)：顶部切换洞洞板和双面包板。按两块 MB-102 的 A–J、1–63 编号定位，支持逐步安装、一次显示一根线、起终点放大、五孔连通示意、单独查看元件与 CSV 接线表。默认仅显示灯和按键，屏幕与声音候选区需自行勾选。模型检查覆盖47个外围元件、64根跳线；设计通过不代表实物通电验收。核心板采用命名接口示意，不能按模型中的排针位置代替实板丝印定位。电源条按50个孔从左数，使用25到26桥接，实物连通仍需万用表确认。

[指定乐曲验收回放](https://woshinidie666-cloud.github.io/rhythm-master-3d/simulator.html) · [从零组装与比赛操作手册](https://woshinidie666-cloud.github.io/rhythm-master-3d/manual.html)

音乐回放直接展示实际 C 核心导出的三份测试轨迹：全部正确 29 分、漏首音 28 分、第二个长音提前松手 28 分。按附件 29 音、D 大调、86 BPM、44 拍逐音核对；网页音频来自核心实际输出的发声时段。它是自动输入的测试回放，图形屏幕是预览，不是实体 OLED 驱动。相同核心已在 STM32F103ZET6 RAM 中自动完整自测；外接电路尚未完成，不能据此认定整机比赛要求通过。

操作手册含元件识别、逐模块试接、万用表检查、焊接、当前程序操作、排错、比赛演示清单，以及 116 根线的元件/引脚端点表。3D 接线现在同步显示两端的元件名、引脚名与定位说明。原 Flash 备份和芯片调试记录只保存在本机，不在本仓库发布。

面向电路初学者的 STM32F103ZET6 电路设计草稿。包含真实三维孔、排针、引脚、元件与导线，支持 171 个组装步骤和 116 根接线的逐根查看。

## 怎么看

- **点击查看**：点元件、引脚或导线，查看中文作用与接法。元件说明中可以单独抽离，旋转观察，再返回原来的步骤。
- **手形拖动**：左键拖动平移。**自由转动**：左键拖动旋转。三种模式均可右键旋转、中键平移。
- **Ctrl + 滚轮**：放大或缩小模型；快捷角度可切换元件面、焊接面及四个侧面。
- **接线教学**默认一次只显示当前一根线。对照 **① 起点、② 终点**，分别点“放大看起点”“看整根走线”“放大看终点”。
- 默认最高画质，播放默认每步 6 秒；可以暂停、调节速度或手动前后切步。

初次下载模型较大，请等待加载。网页全部资源内嵌，没有第三方运行依赖，也不上传浏览者的数据。下载 `index.html` 后可双击离线查看；浏览器需支持 WebGL。

## 设计范围

洞洞板、STM32 核心板、13 颗 LED 与限流电阻、6 个按键与上拉电阻、OLED、候选声音驱动与电源连接。说明卡包含引脚解释、建议规格、候选型号、官方资料与待确认项目。

这是可交互的候选设计。开发板内外排映射、实际供电路径、OLED 兼容电压、发声器额定参数和部分尺寸尚需实物核对；动画验收不代表电气验收。请按说明卡逐项确认，再安排面包板试接与洞洞板焊接。
